# Security

Do not put credentials, private worlds, public/private IP addresses, player data or exploit details in public issues. Use the repository's private vulnerability-reporting feature under Security → Report a vulnerability when available. If it is unavailable, open an issue asking for a private contact channel without including sensitive details.

Only the latest released version is maintained. There is no paid incident-response or guaranteed response-time agreement.

The panel is a powerful single-administrator tool. Access permits running server commands, installing executable mods and changing worlds. Use a strong unique password, protect the Windows account/data directory, update dependencies and keep backups outside the host disk. Local-only access is the default. LAN HTTP is appropriate only on a trusted network; domain access requires HTTPS and a personal password.

The checks and documented tests reduce specific risks; they are not a penetration-test report or a guarantee that vulnerabilities cannot exist. A public administrator panel should be exposed deliberately and monitored by its operator.
