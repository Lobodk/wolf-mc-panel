# Application artwork

The wolf emblem is the default panel logo, Windows launcher icon and installer icon. The panel owner can replace its header logo using the personalization controls.

`app-icon.png` is the original transparent raster generated for this project with OpenAI ImageGen and selected by the project owner. `scripts/build-icons.ps1` scales it without cropping to produce the multi-resolution Windows ICO (16, 24, 32, 48, 64, 128 and 256 pixels) and the web PNG. No Minecraft artwork or third-party logo was used as an input image.

Generation mode: text-to-image, transparent background. Prompt: “An original Windows desktop application icon for Lobo Server Panel: a clean, friendly geometric wolf head, front-facing and symmetric, upright ears, dark charcoal/navy outline, white/ice-blue face and blue eyes. Minimal broad shapes, readable at small sizes, transparent background, square composition. No cubes, words, watermarks or existing brand logos.”
