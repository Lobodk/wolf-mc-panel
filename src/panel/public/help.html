Tu servidor, paso a paso

Wolf MC Panel administra servidores de Minecraft Java en Windows. Puedes utilizarlo desde el mismo PC, desde tu red local o mediante un dominio con HTTPS. El navegador es la interfaz; Minecraft y el panel se ejecutan en el equipo donde los instalas.

1. Instalar y entrar

  1. Instala el programa para tu usuario de Windows. El instalador incluye Node y Caddy. No necesitas instalar estas herramientas por separado.
  2. Abre Wolf MC Panel. La primera vez se abre también ACCESS-KEY.txt con tu clave inicial. Utilízala para entrar.
  3. Abre Seguridad y contraseña para elegir una contraseña personal. La clave inicial dejará de servir para iniciar sesión. La contraseña se guarda protegida en este equipo.
  4. Consulta esta guía cuando lo necesites. Puedes repetir el recorrido desde Ver primeros pasos.

2. Crear un servidor

  1. Pulsa Crear Servidor. Elige Minecraft y, opcionalmente, NeoForge, Forge o Fabric. El catálogo se consulta a los proveedores oficiales. Las versiones experimentales se muestran por separado.
  2. Elige nombre, RAM, dificultad y máximo de jugadores. Cada servidor necesita un puerto propio y comparte los recursos del PC con los demás.
  3. Escribe la dirección para tus amigos y configura el puerto. Desde este mismo equipo puedes conectarte con 127.0.0.1. Desde otro PC de casa utiliza la dirección local del servidor.
  4. Lee y acepta la EULA de Minecraft si estás de acuerdo. El panel prepara Java y los archivos necesarios. La descarga necesita conexión a Internet.
  5. La instalación termina con el servidor apagado. Entra en Administrar y pulsa Iniciar. Comprueba primero la conexión local.

3. Conectar a tus amigos

Para jugar desde fuera de casa necesitas una IP pública y una ruta de entrada, o un servicio de túnel compatible. Un dominio o DDNS facilita recordar la dirección, pero no abre puertos, no evita CG-NAT y no oculta la IP a la que apunta.

  1. Reserva en el router la dirección local del PC que ejecuta Minecraft, para que no cambie.
  2. Reenvía el puerto TCP del juego hacia ese PC. Para el primer servidor suele utilizarse 25565; los demás necesitan puertos diferentes.
  3. Permite ese puerto en el firewall de Windows. El panel puede intentar crear la regla y utilizar UPnP cuando lo solicitas; el router o los permisos pueden impedirlo.
  4. Si tienes CG-NAT o doble NAT, consulta al operador. Compara la dirección WAN del router con tu IP pública sin publicar capturas de esas pantallas.
  5. Prueba desde otra conexión. Algunos routers no permiten utilizar la dirección pública desde dentro de casa.

Abre únicamente los servicios que necesitas. Mantén la autenticación de Minecraft y utiliza whitelist si el servidor es privado. No abras RCON en el router.

Como alternativa externa puedes consultar Playit. Debes revisar sus condiciones, disponibilidad y límites. Wolf MC Panel no está afiliado a ese servicio ni incluye una cuenta o suscripción.

4. Alojar el panel con tu propia dirección

La dirección del panel es independiente de la dirección para jugar. Puedes alojar ambos en el mismo PC o en un equipo Windows dedicado. Para utilizar un alojamiento necesitas que permita procesos persistentes de Node y Java; un hosting web compartido de PHP no suele servir para ello.

  1. Para utilizarlo solo en este PC, conserva Solo desde este PC en Conexión del panel.
  2. Para administrarlo desde otro dispositivo de casa, selecciona Desde la red local, guarda y reinicia el panel. Usa la IP local del PC y el puerto del panel. Permite el acceso solo en tu red privada.
  3. Para acceder desde Internet, configura primero tu contraseña personal. Selecciona Con dominio y HTTPS e introduce una dirección propia, por ejemplo https://panel.ejemplo.com.
  4. Haz que el dominio apunte al equipo correcto y configura los puertos web 80 y 443. Los registros A y AAAA deben corresponder a direcciones que realmente alcancen ese equipo.
  5. Activa Gestionar HTTPS con el Caddy incluido si no utilizas un proxy propio. Guarda y reinicia el panel. Caddy solicitará y renovará los certificados cuando el dominio sea accesible.
  6. Si utilizas un proxy propio, copia la configuración mostrada. Debe ejecutarse en el mismo equipo y conectarse al puerto interno de loopback. No publiques directamente el puerto interno del panel.

Reiniciar el panel no reinicia Minecraft. Cerrar el navegador tampoco lo apaga. El equipo y los procesos deben permanecer encendidos. Si un dominio deja de funcionar, utiliza Recuperar acceso local desde el menú Inicio de Windows.

También puedes ejecutar el código fuente con Node 24 o posterior compatible, utilizando node src/main.cjs. Consulta el README para preparar Caddy y las carpetas de datos cuando no utilizas el instalador.

Configuración y requisitos de los certificados: documentación oficial de Caddy.

5. Ayuda con el router

Busca el modelo exacto en la etiqueta del router. El nombre de los menús cambia según modelo y firmware. En general necesitas Reserva DHCP y Reenvío de puertos, que también puede llamarse NAT, Virtual Server o Port Forwarding.

Selecciona un fabricante para abrir su soporte oficial y buscar el manual de tu modelo.

Abrir soporte oficial

Si el router es de DIGI, Movistar, Orange, Vodafone u otro operador, identifica también el fabricante y consulta al operador cuando la función esté bloqueada. El panel no necesita ni guarda la contraseña del router.

6. Mods y CurseForge

Instala mods de fuentes de confianza. Un mod puede ejecutar código con los permisos de Java. Comprueba Minecraft, loader, dependencias y si cada mod es de cliente, servidor o ambos.

  1. Puedes subir archivos JAR manualmente. El panel identifica sus nombres y archivos para que puedas reconocerlos.
  2. Para buscar en CurseForge necesitas una clave propia autorizada para tu uso. Consulta la guía oficial de solicitud y sus condiciones de API. La aprobación depende de Overwolf.
  3. Describe tu proyecto y uso de forma veraz. Las claves no son transferibles. El programa no incluye la clave del creador ni una clave compartida.
  4. Cuando recibas la autorización correspondiente, guarda la clave en el buscador. La integración consulta versiones compatibles con el servidor seleccionado.
  5. Revisa las dependencias antes de instalar. Algunos autores no permiten descargar mediante terceros; respeta esa decisión y utiliza las opciones permitidas por el autor.
  6. Puedes preparar instalaciones y actualizaciones mientras el servidor está encendido. Los cambios preparados se aplican al reiniciar Minecraft; los mods no se cargan en caliente.

Si utilizas AutoModpack, cada servidor conserva su propia huella. Compártela con tus jugadores mediante una vía de confianza. Recrear un servidor puede cambiarla y requerir que los clientes actualicen su confianza.

7. Copias y cambios de versión

Crea una copia manual cuando quieras y activa las automáticas si las necesitas. La copia automática se renueva cada cuatro horas; las manuales permanecen separadas. Las operaciones se ponen en cola para evitar que escriban a la vez.

La restauración conserva primero una copia del estado actual y deja Minecraft apagado. Verifica la copia y la versión del servidor antes de restaurar. Guarda también una copia independiente en otro disco: una copia en el mismo disco no protege frente a una avería de ese disco.

Actualizar Minecraft puede convertir el mundo. Quitar un mod puede eliminar bloques, objetos o dimensiones. Revisa la compatibilidad de todos los mods y sus dependencias antes de cambiar Minecraft o el loader. Una copia no garantiza que un mod admita migraciones o retrocesos de versión.

Preguntas frecuentes

¿Puedo utilizar un dominio y varios servidores?

Sí. Los servidores pueden compartir IP o dominio con puertos distintos. El panel de administración tiene su dirección web separada. Configurar un dominio no crea automáticamente las reglas del router.

¿Puedo instalar el programa en mi PC y administrar otro?

Instala el panel en el equipo donde se ejecuta Minecraft. Desde tu PC principal abre su dirección en el navegador. No necesitas instalar otra copia del programa para verlo. Esta versión administra procesos del equipo donde está instalada.

¿Qué sistemas admite esta versión?

La distribución y las pruebas se centran en Windows x64. El código fuente puede ejecutarse sin el instalador en Windows con sus dependencias. Linux, Docker y agentes para controlar otros equipos no se anuncian como soportados en esta versión.

¿Actualizar o desinstalar borra mis mundos?

El programa y los datos se guardan por separado. El desinstalador conserva los datos. Haz una copia independiente antes de actualizar. La carpeta predeterminada es %LOCALAPPDATA%/WolfMCPanel/data; las instalaciones anteriores pueden conservar %LOCALAPPDATA%/LoboServerPanel/data.

¿Cómo recupero el acceso si olvido la contraseña?

Abre Inicio → Wolf MC Panel → Restablecer contraseña.

Confirma en Windows. Minecraft seguirá encendido.

Entra con la clave temporal que se abrirá y crea una contraseña nueva.

Se cierran las sesiones y el acceso queda limitado a este PC hasta volver a activar LAN o HTTPS.

Sin instalador: ejecuta scripts/recuperar-contrasena.ps1. En el panel personal, utiliza su acceso de recuperación de Windows.

¿Qué ocurre si cierro el navegador?

El panel sigue funcionando en segundo plano. Detener panel cierra el panel y su proxy HTTPS; no apaga los servidores Minecraft que ya estaban iniciados. Apaga cada servidor desde sus controles cuando quieras detenerlo.

¿Puedo cambiar realmente la fuente de Minecraft?

El editor ofrece letras decorativas y formato que cambian el texto enviado al juego. Su aspecto depende del cliente y del paquete de recursos. Cargar una fuente arbitraria en la lista de servidores requiere cambios en el cliente.

¿Qué idiomas incluye?

Español, inglés, alemán, francés, turco y portugués de Brasil. Puedes cambiar el idioma en el selector del panel y la guía. Los registros del juego y las descripciones de mods conservan el idioma de su proveedor.

¿Es obligatorio apoyar en Ko-fi?

No. El apoyo es voluntario, no desbloquea funciones y no constituye una promesa de soporte individual.
